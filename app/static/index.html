Which cores should a search use?

A short calibration times each thread set on a slice of the database and keeps the default (one thread per physical core) unless another set is more than 5% faster. On this laptop the benchmarks found the default best (M6 E2; E8: 30 of 30 calibrations agreed), so it is optional.
