## Corrections to Phase 1 statements

- Phase 1 reported that searches found no peer-reviewed evaluation of OpenMP loop schedules on Alder Lake. **That was wrong: S14 is exactly such a study** (it was missed because it is published under the PMCSched name). `RESEARCH_FINDINGS.md` §3 and `PROJECT_DECISION.md` should be read with this correction; the updated comparison is in `NOVELTY_AND_PRIOR_ART_COMPARISON.md`.
- Phase 1's description of AID relied partly on an automated summary of S1. S14 (read directly) confirms the mechanisms of AID-static, AID-hybrid and AID-dynamic as described.

## Searches that found nothing

- Phase 1: a search for evaluations of OpenMP loop schedules on Alder/Raptor Lake returned only vendor documentation — superseded by S14 above.
- Phase 1B: one search for Smith–Waterman or sequence-alignment evaluations on Intel hybrid (P+E) CPUs returned nothing relevant. One search only.
- Phase 1B: no source was found that combines wet/dry-aware load balancing in a flood model with cores of unequal speed. This is **one search plus reading abstracts**; S20 in particular has not been read in full. Say "we did not find", never "none exists".
